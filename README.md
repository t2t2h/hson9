# DomainSniffer (Theos)

dylib يراقب اتصالات اللعبة ويسجّل النطاقات والـ IP، مع قائمة عائمة وحفظ.

## ما يلتقطه
- DNS: `getaddrinfo` و `gethostbyname` (يشمل SDK الأصلية مثل Agora / Zego)
- HTTP / رفع / تحميل / WebSocket عبر `NSURLSession`
- اتصالات IP مباشرة: `connect` و `sendto` (UDP)
- يميّز النطاقات المحجوبة من NextDNS (الرد 0.0.0.0 أو ::) بعلامة ⛔، والفاشلة بـ ⚠️

## البناء
```
export THEOS=~/theos
make package
```
الناتج: `packages/*.deb` والملف `.theos/obj/DomainSniffer.dylib`

## الحقن (بدون جيلبريك)
استخدم Sideloadly أو ESign أو Feather لحقن `DomainSniffer.dylib` في الـ IPA.
مهم: فعّل خيار حقن Cydia Substrate / ElleKit لأن الـ dylib يعتمد على `MSHookFunction`.

## الجديد في 1.1.0
### ⛔ حجب مباشر عبر NextDNS API
1. اضغط **🔑 NextDNS** في أعلى القائمة وألصق مفتاح API (من my.nextdns.io/account). Profile ID اختياري، يُكتشف تلقائياً (أول Profile).
2. اضغط على أي نطاق ← **⛔ حجب (NextDNS)** ← يُرسَل مباشرة إلى Denylist ويظهر عليه 🚫.
   (للسطر من نوع IP تظهر خيارات حجب النطاقات المرتبطة به.)
- المفتاح محفوظ في `Documents/DomainSniffer/settings.json` داخل ملفات اللعبة، نص عادي. زر المشاركة لا يرسل هذا الملف.

### 🔁 قواعد الاستبدال
- اضغط على أي سطر ← **🔁 استبدال…** أو زر **🔁 استبدال / قواعد** لإدارة القواعد.
- أمثلة: `1.1.1.1 ← 8.8.8.8` ، `example.com ← 1.2.3.4` ، `*.example.com ← 1.2.3.4`
- كل قاعدة لها مفتاح تشغيل/إيقاف، وتُحفظ التفعيلات تلقائياً وتبقى بعد الخروج من اللعبة والدخول مرة ثانية.
- التطبيق: نطاق ← عند DNS (`getaddrinfo`/`gethostbyname`)، و IP ← عند `connect`/`sendto` (المنفذ يبقى كما هو، ونفس نوع IPv4/IPv6 فقط).

## الاستخدام
- زر 🌐 عائم قابل للسحب، اضغطه لفتح القائمة.
- بحث + فلتر: الكل / نطاقات / IP / محجوب.
- الضغط على أي سطر يفتح قائمة: حجب / استبدال / نسخ.
- 💾 حفظ: يكتب الملفات في `Documents/DomainSniffer/`
  - `denylist_nextdns.txt` (النطاقات غير المحجوبة بسطر لكل نطاق، جاهزة للصق في NextDNS)
  - `domains.txt` و `ips.txt` و `data.json`
- 📤 مشاركة: يفتح قائمة المشاركة لحفظ الملفات في تطبيق الملفات.
- 📋 نسخ Denylist: ينسخ قائمة النطاقات للحافظة.
- 🗑 مسح: يحذف السجل.
- السجل يُحفظ تلقائياً كل 5 ثوانٍ ويُحمَّل عند فتح اللعبة مجدداً.
